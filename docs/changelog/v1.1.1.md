# v1.1.1

## Patches

- Running **Update** no longer crashes the app. The stop → update → restart burst could make Avalonia's
  built-in "scroll to selected item" call `ScrollIntoView` during an invalid layout pass and throw
  "Invalid Arrange rectangle", which went unhandled. The lists no longer auto-scroll to the selection (the
  log already follows its own tail), and the tail-scroll is skipped while the window is hidden or unmeasured
  and guarded so a transient layout error can never crash the app.
