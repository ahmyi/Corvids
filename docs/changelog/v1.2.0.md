# v1.2.0

## Features

- A local control API so AI agents and other tools can drive Corvids. It is a loopback HTTP + JSON server,
  bound to `127.0.0.1` only and guarded by a bearer token, enabled from Settings ("Enable local control
  API"). Off by default; a token is generated the first time it is turned on.
- Endpoints:
  - `GET /ping` — liveness check.
  - `GET /apps` — list apps with status, running, pid, uptime, folder, command, and listening ports.
  - `GET /apps/{id}` — one app (by id or name).
  - `GET /apps/{id}/logs?lines=N` — recent log lines.
  - `POST /apps/{id}/{start|stop|restart|update}` — control the app.
  - All requests require `Authorization: Bearer <token>` (or `?token=`). `POST` needs a body or
    `Content-Length: 0`.
